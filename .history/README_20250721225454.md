# EZApply

**EZApply** is an AI-powered desktop application that automates job applications on Applicant-Tracking-System (ATS) portals—beginning with the **NHS Trac** platform.  
It fills every field, writes bespoke answers using large-language models, and keeps *all* data on your computer.

> *Runs locally / Ships as a single exe · dmg · AppImage / No web back-end required*

---

## ✨ Why EZApply?

| Pain-point | EZApply’s fix |
|------------|---------------|
| Re-typing personal details on every form | One master profile auto-fills everything. |
| Writing fresh “supporting information” each time | AI Answer Engine pulls quantified stories from your résumé and crafts tailored paragraphs. |
| Losing track of what you’ve applied for | Built-in analytics & file-level run history. |
| Privacy & security | Manual portal login, encrypted API keys, local Postgres DB—nothing sent to third-party servers (LLM calls only if you enable them). |

---

## 📋 Feature Overview

### 1. Portal Automation
- **Trac adapter** (all NHS skins) — MVP  
- Upcoming: NHS Jobs Beta SPA, Workday, Greenhouse  
- Playwright-driven browser control with human-like pacing & page checkpoints  
- Colour overlay (green / amber / red) shows field-mapping confidence live on screen  

### 2. AI Answer Engine
- Multi-provider routing:  
  `GPT-4o` · `Claude 3.5` · `Gemini 1.5` · local `Ollama` models  
- Word/char-limit guard; cost-aware model selection  
- Retrieves most relevant sentences from a **Story Bank** (vector search with pgvector)  

### 3. Document Intelligence
- Drag-and-drop résumé / cover-letter (.pdf | .docx)  
- Python ingest service extracts sentences, education, employment history  
- Parsed data auto-populates your profile and feeds the Story Bank  

### 4. User Interface
- **React + Tailwind** UI inside a lightweight **Tauri** shell  
- Hot-module reload in dev mode (`npm run tauri dev`)  
- Sidebar tabs: Work Prefs · Personal · Education · Employment · NHS Service · References · Equal Opportunities · Import/Reset · API Keys · Data Inspector  
- Run Dashboard: queue, progress bars, live log tail, screenshot preview  

### 5. Storage & Analytics
- Local **PostgreSQL 16** (Docker) with `pgvector` extension  
- Folder layout under `~/EZApply/` (see below)  
- success / failed / skipped JSONs per run, screenshots on submit or error  
- In-app charts: apps/day, token cost, success-rate, time/section  

### 6. Security & Safety
- Manual portal login—EZApply never stores passwords  
- Encrypted storage of API keys (Postgres `pgcrypto`)  
- Rate-limited clicks, duplicate-application detector, blacklist enforcement  
- Git secret-scanning pre-commit hook & GitHub Action

| Layer | Tech |
|-------|------|
| **GUI** | React (Typescript) + Tailwind CSS + shadcn/ui |

## 📂 Storage Layout (local-first)

```
\~/EZApply/
├─ profiles/               # YAML exports for backup
├─ documents/              # uploaded PDFs, generated letters
├─ runs/
│   └─ 2025-07-21_0930/    # one folder per automation run
│        success.json
│        failed.json
│        screenshots/
├─ logs/
│   └─ 2025-07-21.log
└─ postgres/               # Docker volume for database
```

All structured data lives in Postgres; files are referenced by absolute path.

## 🛣️ User Workflow

1. **Install & Launch**  
   Download the platform-specific installer → open EZApply from the desktop shortcut.

2. **Create / Import Profile**  
   The welcome wizard lets you either fill basic info or drop a résumé PDF.  
   Parsed data appear side-by-side for one-click approval.

3. **Set Work Preferences**  
   Choose platform (e.g., *NHS Trac*), job titles, locations, salary filters, and blacklists.

4. **Dry-Run**  
   EZApply opens a Playwright-controlled Chrome window, you log in manually.  
   Overlay colours show confidence of each mapped field.

5. **Review & Submit**  
   A modal lists every field and AI-generated paragraph. You approve → EZApply clicks *Submit*. Confirmation reference, screenshot, and full HTML dump saved.

6. **Analytics & History**  
   Dashboard updates with success stats. All artefacts reside under `runs/` and in the database for later querying.

## 🚀 Quick Start (Dev Mode)

```bash
# Clone
git clone https://github.com/your-name/ezapply.git
cd ezapply

# Start Postgres
docker compose up -d

# Install JS deps & launch hot-reload desktop window
npm install
npm run tauri dev
```

Now drag a résumé PDF into the window—sentences will populate Postgres and appear in the Story Bank table.
